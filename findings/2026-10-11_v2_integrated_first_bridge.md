# V2 Integrated First Bridge: P Influences A Without Structural Object Evidence

## Headline

The first V1-derived P/A bridge preserved exact V1 behavior when its new
couplings were disabled. Enabling an independent P-to-A influence changed
actuality and accumulated tension without collapsing P into A, but did not yet
change median vortex count or produce measurable compression at this run
length. This is a continuity result, not an object result.

## Model and Comparison

`src/genesis_v2_integrated/` retains the V1 sequence:

`relational mismatch -> tau -> displacement -> compression`.

It adds independent potential direction `P = (px, py)`, actual orientation
`A = theta`, and edge-level relation memory `R = (rx, ry)`. The comparison
held the V1 substrate fixed across five `N=64`, 2,000-frame runs:

- **V1 parity:** all added P/A/R couplings zero;
- **P-to-A bridge:** P transport `0.03`, source restoration `0.10`, and
  potential-to-actual influence `0.10`; no A-to-P copying and no relation
  memory were enabled.

## Median Final Measurements

| Condition | P/A alignment | Mean tension | Mean compression | Vortex count |
|---|---:|---:|---:|---:|
| V1 parity | 0.0086 | 0.0070 | 0.00000012 | 30 |
| P-to-A bridge | 0.2733 | 0.1019 | 0.00000051 | 28 |

## Interpretation

Potentiality did not become a copy of actuality: final P/A alignment was well
below one, while the P-to-A condition changed the realized field and increased
inherited V1 tension. The small compression values and unchanged median vortex
count mean this run does **not** show a structural stabilization effect, much
less a higher-order object.

## Next Test

Add relation-memory tension as the next single causal link, then compare it to
this baseline. The question is whether stored edge incompatibility changes the
distribution, lifetime, or compression context of tracked vortex-pair
candidates without causing P/A collapse or a global coarsening attractor.
