## What is ready

`src/genesis_sandbox/` supplies a separate native PyQt interface around
`src/genesis_gallery/legacy.py`. Geometry on/off lanes start from identical
angles and receive the same timestamped brush prescriptions. Play/pause,
single step, queued growth, seed reset, Set/Turn brushes and fixed-scale theta/C
views work. Painting pauses; only theta is edited. The controls retain distinct
structural states throughout rather than toggling stale geometry mid-run.

Export writes paired PNG, full float64 fields and JSON recipe to a new folder
under `work/sandbox_exports/`. Replay with:

```powershell
.venv\Scripts\python.exe -B -m src.genesis_sandbox --replay "path\to\recipe.json"
```

Replay checks matching dynamics source fingerprints and parameters, then
recomputes the history. Exact replay is verified in the current environment;
long sessions take proportionally longer to replay. Brush dragging interpolates
stamps, and overlapping Turn stamps accumulate. The default is Set orientation.
