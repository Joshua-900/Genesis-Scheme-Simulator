# Genesis Scheme Home

The Genesis Scheme is a theory-first project. This vault keeps the conceptual framework primary while preserving the software and experiments that develop, represent, and test it.

## How to read this vault

1. Start with the canonical theory and mathematical definitions.
2. Follow operator and invariant notes to understand the formal machinery.
3. Read implementation notes to see how the current simulator expresses the theory.
4. Read experiments as evidence with stated limits, not as automatic replacements for theory.
5. Use research and session notes for provenance, alternatives, and unresolved questions.

## Authority boundaries

| Material | Role | Authority |
| --- | --- | --- |
| Theory | Definitions, ontology, mathematics, invariants | Primary |
| Implementation | Current software representation | Derived and testable |
| Experiments | Observations and evidence | Supporting or challenging |
| Research and sessions | Exploration and provenance | Non-authoritative until reviewed |
