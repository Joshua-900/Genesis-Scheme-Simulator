# Canonical Values

This note is the single source of truth for the official values used by vault notes.

## Status

- `draft`
- `in-progress`
- `complete`
- `archived`
- `deprecated`

## Confidence

- `proven`
- `vetted`
- `tentative`
- `speculative`

## Authority

`canonical` is a boolean:

- `true`: authoritative current standard or statement.
- `false`: exploratory, historical, provisional, or subordinate material.

`status` describes lifecycle. `confidence` describes trust or certainty. `canonical` describes authority. They must not be used as substitutes for one another.
